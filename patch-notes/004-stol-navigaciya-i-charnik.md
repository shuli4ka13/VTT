## Изменено

1. **Навигация.** Было: четыре страницы, свайп между ними. Стало: разделы на нижней панели, между ними только касанием. Игрок — Сцена · Чаты · Чарник; ведущий — Сцена · Чаты · Листы · Стол. Внутри раздела — подразделы бейджиками под шапкой, касанием или свайпом. Задача T1.
2. **Журнал.** Больше не отдельная страница: подраздел «Системный» раздела «Чаты», рядом с «Общением». Задача T14.
3. **Настройки ведущего.** Фон, видимость здоровья и правила стола — раздел «Стол» с тремя подразделами. Задачи T7, T11, T12.

## Добавлено

4. **Чарник по разделам.** Подразделы чарника — закладки листа из системы: `system.pages`, в конструкторе «+ страница» на вкладке «Лист». Отдельной модели не нужно, в образце D&D закладки уже есть. Задача T8.
5. **Закреплённая сводка.** Шапка листа стоит над бейджиками сжатой строкой: хиты и защита видны в любом разделе.
6. **Лист без закладок** открывается одной лентой с прокруткой вниз. Автора делить не заставляем.
7. **Заполнение нового листа** идёт по тем же разделам. Задача T9.

## Если что-то уже сделано по v1

- Свайп между страницами верхнего уровня убрать, оставить только внутри раздела.
- Экран журнала перенести подразделом в «Чаты».
- Длинный лист не выбрасывать: это вид для систем без закладок.
