## Добавлено

1. **26 пар «сейчас → будет».** Слева настоящий снимок нынешнего экрана или карточка «сейчас так нельзя» с причинами, справа «солнце».
   - Строки 1–8 — те же данные эффекта в двух видах: Атака, Урон, Щит, При смерти, Огненный шар, Скрытая атака, Волшебная стрела, Лежит.
   - Строки 9–18 — варианты с правками из `vtt-effects-tasks.md`.
   - Строки 19–26 — окна пузырей, набор ядра, привязка, цепочка, карта связей, класс.
2. **Раздел «Сравнение с нынешним конструктором»** в спецификации: какие нынешние экраны новый вид заменяет.

## Что выяснилось по нынешнему конструктору

Часть задуманного уже есть в другом виде — это нужно заменить, а не построить рядом:

| Сейчас | В «солнце» |
| --- | --- |
| ящик «что будет дальше · кто может изменить» у шага-вызова | окно вызова и швы |
| «Правила → Метки», договор метки | окно метки |
| «Правила → Быстрые настройки», переключатель крита | правило «Крит» (E5) |
| панель «Рядом»: «Готовое» и «Проба» | набор ядра и док «Пробный прогон» |

## Что видно на парах с теми же данными

- В «Уроне» сейчас сидят провал спасброска от смерти и «Мёртв»; вызвавшему он ничего не отдаёт.
- «Скрытая атака» — кнопка, не связанная с «Атакой»; условия и удвоение на крите стол не проверяет.
- «Лежит» даёт преимущество любой атаке по лежащему: «вплотную» данные не различают.
- «Волшебная стрела» отдаёт весь бросок каждой цели, а не по стреле.
- «Пламя клинка» слушает «Атаку» по имени эффекта, а не по метке.

Это те же расхождения, что закрывают задачи S1–S7 документа эффектов.
