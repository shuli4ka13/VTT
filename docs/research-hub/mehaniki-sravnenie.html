Механики двух систем и что нужно для VTT

Строка — механическая роль по движковому блоку. Колонки D&D / Cyberpunk — как её решает каждая система. Новая колонка 🛠 Что нужно — конкретный узел / контрол / хук, который надо построить в VTT, чтобы это автоматизировать. Покрытие считается по системам. Всё редактируется.
Общих 0 D&D 0 Cyberpunk 0
Правка: кликай в ячейку и меняй. Пустая ячейка D&D/CP или — = «нет в системе». Формулы — в <code>…</code>. Есть добавление/удаление строк. «Сохранить» — в этот браузер; «JSON» — выгрузить.
Как это использовать для VTT. Колонка «Что нужно» — это дорожная карта движка автоматизации: собери уникальные узлы из неё (движок бросков, стек модификаторов, конвейер урона, библиотека состояний, триггер-события, ресурсы, шаблоны карты) — и обе системы автоматизируются одними и теми же кубиками. «Общие» строки строишь один раз (ядро), «только D&D» и «только CP» — тоглы поверх. Это прямой вход в матрицу реализации.
