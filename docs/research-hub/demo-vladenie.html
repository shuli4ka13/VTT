Кружок владения — и из чего он собран

Тот самый кружочек у навыка. Клик циклит состояние — нет → владение → компетентность → половина — и к навыку сразу прибавляется бонус мастерства с нужным множителем. Слева живой лист (кликай кружки, меняй уровень и характеристики), справа — из каких узлов конструктора это собирается.
Бонус мастерства +3
◯НавыкРасчётИтог
нет владения ×0 владение ×1 компетентность ×2 половина ×0.5
Из чего это собрано
1
🎛️ Стейтовый контрол (кружок)
Циклическая кнопка на 4 состояния. Её значение — множитель 0 / 1 / 2 / 0.5. Это тот же «управляющий элемент», что Radio/множитель из списка контролов VTT.
2
🧮 Узел формулы «Бонус мастерства»
БМ = 2 + ⌊(ур−1)/4⌋ — производное от уровня, считается само.
3
➕ Узел «Модификатор»
Тип MULT→FLAT: берёт БМ, умножает на значение кружка, прибавляет к броску навыка. Условие-гейт: «если есть владение».
4
🔗 Привязка к листу
Строка навыка на чарнике связана с формулой мод.хар + множитель×БМ → итог обновляется при клике.
В нашей модели это «Бонус за умение» из матрицы: контрол + формула БМ + узел «Модификатор». Один раз собрал — работает для всех навыков, обеих систем (в Cyberpunk кружок был бы «есть навык», а множитель — сам уровень навыка).
