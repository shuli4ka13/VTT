Справочник · D&D 5e

Все механики — в формулах

Разбор ядра правил D&D 5e как формул: что именно должен уметь считать конструктор автоматизации, чтобы собрать эту систему. Обозначения: мод — модификатор характеристики, PB — бонус мастерства, КБ — класс брони, ⌊x⌋ — округление вниз.

Основа

Модификатор характеристики
мод = ⌊(характеристика − 10) / 2⌋
16 → +3 · 8 → −1 · 20 → +5 · 10 → 0
Бонус мастерства (PB)
PB = 2 + ⌊(уровень − 1) / 4⌋
ур. 1–4 → +2, 5–8 → +3, 9–12 → +4, 13–16 → +5, 17–20 → +6

Проверки d20

Проверка характеристики
d20 + мод vs Сложность (DC)
Успех, если результат ≥ DC
Проверка навыка
d20 + мод + (PB если владение)
Экспертиза → PB × 2
Спасбросок
d20 + мод + (PB если владение спасом)
Пассивная проверка
10 + все модификаторы
преимущество +5 · помеха −5. Пасс. Внимательность = 10+Wis+PB
Преимущество / Помеха
бросить 2d20 → взять больший / меньший
не суммируются: несколько преимуществ = одно

Атака

Бросок атаки оружием
d20 + мод + (PB если владение) vs КБ
мод = Сила (ближний) или Ловкость (фехт./дальний). Попал, если ≥ КБ
Критическое попадание
натуральная 20 → попадание + удвоение костей урона
натуральная 1 → автопромах
Атака заклинанием
d20 + мод заклинателя + PB vs КБ
Сложность спасброска заклинания
DC = 8 + мод заклинателя + PB
Модификатор заклинательной атаки
= мод заклинателя + PB

Урон

Урон оружием
кость оружия + мод (+ бонусы)
длинный меч: 1d8+3. Мод обычно тот же, что в атаке
Критический урон
2× кости + мод
удваиваются только кости, модификатор — нет. Крит 1d8+3 → 2d8+3
Сопротивление / Уязвимость
урон × ½ / урон × 2
сопротивление считается после всех модификаторов, округл. вниз
Внезапная атака (плут)
+ ⌈уровень / 2⌉ d6
ур.1 → 1d6, ур.5 → 3d6, ур.20 → 10d6
Урон падения
1d6 за каждые 3 м (макс 20d6)

Защита (КБ)

Без брони
КБ = 10 + мод Ловкости
Лёгкая броня
КБ = база + мод Ловкости
кожа = 11 + Ловк
Средняя броня
КБ = база + min(мод Ловкости, +2)
кольчужная рубаха = 13 + min(Ловк,2)
Тяжёлая броня
КБ = фиксированное (Ловкость не учитывается)
латы = 18
Щит
+2 к КБ
Укрытие
+2 (½) / +5 (¾) к КБ и спасам Ловкости
Без доспехов (монах/варвар)
10 + Ловк + Мудр / 10 + Ловк + Тело

Здоровье

Макс. хиты на 1 уровне
макс. кость хитов + мод Тела
воин (d10), Тело +2 → 12
Хиты за уровень
бросок кости хитов (или среднее) + мод Тела
среднее кости = ⌊грань/2⌋ + 1: d8→5, d10→6, d12→7
Спасброски от смерти
d20: ≥10 успех, <10 провал
3 успеха = стабилизация · 3 провала = смерть · нат.20 = +1 ХП · нат.1 = 2 провала
Спасбросок концентрации
спас Тела, DC = max(10, ⌊урон / 2⌋)
Временные хиты
не суммируются → берётся большее
Лечение
+хиты, но не выше максимума

Движение и физика

Инициатива
d20 + мод Ловкости
Прыжок в длину (с разбега)
= значение Силы (в футах)
без разбега → половина
Прыжок в высоту
= 3 + мод Силы (в футах)
Грузоподъёмность
= Сила × 15 (фунтов)
толкать/тащить/поднимать → Сила × 30
Захват / Толчок
состязание: Атлетика(Сила) vs Атлетика/Акробатика

Отдых и состояния

Короткий отдых
трата костей хитов: бросок + мод Тела за штуку
Долгий отдых
полные ХП + восстанов. ⌊кости хитов / 2⌋ (мин 1)
Истощение
6 уровней, эффекты кумулятивны
1: помеха на проверки · 2: ½ скорости · 3: помеха атак и спасов · 4: ½ макс. ХП · 5: скорость 0 · 6: смерть

Прибавка характеристик
на ур. 4, 8, 12, 16, 19 → +2 к одной / +1 к двум (макс 20)
основа / прогрессия проверки атака урон защита здоровье движение
Что это даёт конструктору. Почти всё D&D сводится к паре примитивов: d20 + модификаторы vs порог (проверки, атаки, спасы) и кости урона + модификатор → в ХП. Остальное — это округления (⌊ ⌋), пороги (min/max, укрытие, средняя броня), таблицы (PB, опыт, ячейки) и ветвления (крит, сопротивление, концентрация). Если движок автоматизации умеет бросок · модификатор · сравнение · min/max/округление · таблицу · ветвление — он собирает всю D&D.
