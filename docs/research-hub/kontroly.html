Конструктор · управляющие элементы листа

Палитра умных контролов

Кружок владения — один из класса инлайн-контролов, которые делают лист быстрым: щёлкнул — значение поменялось, формула пересчиталась, эффект применился. Ниже — живые примеры (кликай!). Каждый подписан: тип, какую механику водит, поведение. Это готовая палитра «управляющих элементов» для конструктора.
Общий принцип. Каждый контрол — это привязка: у него есть значение (число / состояние / множитель), и оно течёт в узел — формулу, модификатор или конвейер. В конструкторе мастер кладёт контрол на строку листа и говорит «это пишет вот в это поле / крутит вот этот модификатор». Один набор из ~12 контролов покрывает всё управление обеими системами. Дальше их можно комбинировать: пип-трекер + степпер = ресурс, сегменты + кубик-кнопка = выбор режима и бросок, тоггл + чип = состояние с источником.
