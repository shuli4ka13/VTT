Матрица требований

Что нужно построить, чтобы движок выдал обе системы. Строка — требование. D&D / Cyberpunk — нужно системе (нужно / опция / —). Приоритет: P0 (нужно обеим — ядро), P1 (нужно одной), P2 (по желанию). Статус — клик меняет. Готовность каждой системы считается сама.
Готовность D&D 5e0%
Готовность Cyberpunk RED0%
P0 0 P1 0 P2 0
Как пользоваться. Это дорожная карта движка: сортируй по «Осталось» — видно, что доделать; по «Ядро P0» — что нужно обеим системам в первую очередь. Полоски сверху показывают, насколько близко каждая система к «играбельна на движке» (доля её нужных требований со статусом Готово). D&D-специфика (уровни, преим/помеха, ячейки) и Cyberpunk-специфика (взрывной кубик, абляция, Удача, Гуманность, крит-травмы) — это P1, включаются под систему; P0 — общий фундамент.
