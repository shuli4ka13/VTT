# Справочная путей: одно знание «что значит это имя» для проверки, расчёта и редактора

Заказчик 14.10.2026: в конструкторе ссылки показываются сырым текстом там, где ждёшь фишку и слова
(`«ресурс.left»`, `"ловкость"` в кавычках, `@попадание.попал`). Разбор показал, что причина не в показе:
путь вида «лист → таблица → строка → колонка» разбирают три разных места — проверка («Проблемы»),
расчёт и редактор, — и каждое слепо там, где видят другие.

Принцип проекта (`CLAUDE.md`): словарь мишеней выводится из системы и нигде отдельно не хранится.
Здесь то же правило уровнем выше: что значит путь в формуле, знает движок, остальные спрашивают его.

## Что есть сейчас

Опыт на мире D&D (опечатка подложена, проверка и расчёт прогнаны):

| Опечатка в | Проверка | Расчёт | Редактор |
|---|---|---|---|
| колонке строки цикла `@носитель.ресурс.shortt` | ловит | — | верное `ресурс.short` тоже сырым текстом |
| колонке входа-выбора `@кто.характеристика.savee` | ловит | — | верное — сырым текстом |
| итоге по метке `@попадание.попалл` | ловит | — | верное — сырым текстом |
| колонке поля-таблицы `@abilities.ловкость.modd` | молчит | молча `undefined` | сырой текст (единственный сигнал) |
| строке поля-таблицы `@abilities.ловкостьь.mod` | молчит | ошибка только при расчёте | сырой текст |
| колонке за ссылкой `@class_name.spell_ability.modd` | молчит | — | сырой текст |
| значении входа-выбора `"мудростьь"` | молчит | — | `"мудростьь"` в кавычках |

Где именно:

- Проверка. `references.ts: withAddresses` превращает `таблица.строка.колонка` в ссылку-адрес, а
  `lint.ts: danglingText` принимает её, если есть таблица (`ref.path === ref.key && declared.table.has(…)`):
  строка и колонка не проверяются. Путь за полем-ссылкой (`@поле.колонка…`) не проверяется вовсе
  (ветка `dotted` и ссылки `sheet` смотрят только на голову). Литерал во входе-выборе вызова не сверяется
  со строками таблицы `from`. При опечатке в имени строки цикла (`@носитель.ресурсы.short`) совет «заведите
  поле на вкладке «Лист»» ведёт не туда.
- Расчёт. `navigate.ts: resolveAddress` при неизвестной колонке зовёт `readCell` → `lookupCell` и молча
  возвращает пусто; `walk`/`reach` (путь за ссылкой) колонку проверяют.
- Редактор. Фишка — только для имени из словаря места (`formula-chips.tsx: partsOf/known`). Пути за полями-
  ссылками — готовый перечень `apps/web/src/ui/paths.ts: fieldPaths` с потолком в три шага. Словарь карточки
  шага (`slots.tsx: namesOf`) знает колонки только у входов-выборов, не у строки цикла. Фразы подписки
  (`handler-card.tsx: outcomesOf`) — только для подписки на один эффект, не на метку. Вход-выбор вызова
  (`call-editor.tsx`) — поле формулы, выбранная строка пишется литералом и так и показывается.
- `names-at.ts` знает строку цикла и вход-выбор (`from`), но без колонок-детей; у затравки по метке
  (`heard`) подпись шага — слово типа «Вызов», а не имя вызванного эффекта.

## Решение

### 1. Справочная — `packages/engine/src/model/paths.ts`

Разбор пути шаг за шагом по видам, с подписью на каждом шаге. Списком не является: глубина не ограничена.

- `walkColumns(system, table, path)` — от строки таблицы по колонкам, через колонки-ссылки дальше.
  `value` — служебная колонка значения строки. Итог: `{ ok: true, label }` (подписи колонок через « → »)
  или `{ ok: false, text }` — «у таблицы «Т» нет колонки «к»», «колонка «к» не из таблицы — дальше «…»
  идти некуда».
- `walkSheet(system, path)` — путь по листу в том же порядке, что расчёт (`calc.ts: pass.resolve`):
  точный тег поля (`abilities.ловкость.mod`, `class_name`) → id эффекта без хвоста (сколько раз висит) →
  адрес в таблице со строками (`таблица.строка[.колонка…]`, не диапазон и не таблица-поле; строка — по ключу
  `rowKeyOf`) с ошибками «нет строки» / «нет колонки» → голова-поле со ссылкой и `walkColumns` дальше.
  Итог `null`, если путь к листу не относится. `@строка.…` (переписывается до разбора), Pick
  (`@лист.таблица.[…].колонка`) и `@вещь.…` сюда не подаются — у них свои ветки.
- Через колонку-список (`many`) дальше идти нельзя — ошибка словами. Колонка-ссылка — `choice` или `number`
  с `from` (`linkOf`); `value` в конце пути допустима как служебная колонка значения строки.
- `columnChoices(system, table)` и `sheetChoices(system)` — перечень для подсказок при наборе (бывшие
  `columnPaths`/`fieldPaths` веба), строятся тем же обходом. Перечень нужен только подсказкам; узнавание
  и подписи идут через `walk*`.

### 2. `names-at.ts`

- У имени-выбора с таблицей (вход, затравка-вход, строка цикла) — `children` = колонки таблицы
  (`columnChoices`).
- У затравки-шага по метке — подпись вызванного эффекта («Бросок атаки»), как у шагов своей цепочки.

### 3. Проверка

- Ссылка-адрес и путь за полем — через `walkSheet`; ошибка — текстом справочной.
- Литерал во входе-выборе вызова и наложения — сверка со строками таблицы `from`:
  «во вход «Чем спасается» вызова «Спасбросок» передано «мудростьь» — в таблице «Характеристики» такой строки нет».
  Литерал — только цельный текст из разбора формулы (не ссылка, не выражение), сравнение с сырым значением
  строки (`rowByKey`), таблицы-диапазоны, книжные, одиночные и с ответом «иначе» (`otherwise`) не сверяются.
- Неизвестная голова пути через лист при строках цикла в области видимости — «у листа нет поля «ресурсы»;
  строка цикла здесь зовётся «ресурс»».
- Страховка — существующий тест «все миры-образцы проходят проверку без ошибок» (`model.lint.test.ts`).
  В шести образцах 1676 путей к полям листа, все разбираются.

### 4. Расчёт

`resolveAddress`: неизвестная колонка — ошибка движка со словами справочной (`walkColumns`), как у `walk`.
Страховка — тест: все листы образцов считаются без ошибки «нет колонки».

### 5. Редактор

Имя на экране показывается несколькими дорогами; все они теперь спрашивают одно и то же:

- путь по листу — справочную (`ui/paths.ts: sheetPathLabel` → `walkSheet`): фишки (`formula-chips.tsx:
  plainLabel/knownSheetName`) и слова (`formula-labels.ts: labelOfTag/formulaAsLabels`, через них —
  `formula-words.ts` и пересказ шага `readback.ts`). Фишкой становится только путь, который справочная
  разобрала без ошибки — опечатка по-прежнему видна сырым текстом и теперь ещё и в «Проблемах».
  Перечни для подсказок (`fieldPaths`, `columnPaths`) — реэкспорт `sheetChoices`/`columnChoices` движка;
- имена места — `namesAt` движка: карточка шага получает их от цепочки (`effects/names.ts: placeNamesAt`,
  как листы через `sheetsAt`) в `SlotContext.names`; ими дополняются словарь карточки (`slots.tsx: namesOf`),
  поле значения (`value-field.tsx`) и заголовок карточки (`effects/words.ts: titleOf` — «Изменить «ресурс →
  Осталось»»). Уже существующие подписи карточки не перебиваются: имена движка только дополняют.
  Подпись колонки строки — «ресурс → Осталось»; итога шага — по прежнему правилу карточки («попадание»,
  «урон — итог»);
- «Только если» подписки — словарь места из `namesAt`; фразы исхода для подписки на метку — итоги-да/нет
  затравки-шага («Бросок атаки — попадание», «— крит»), если подписка не на один эффект;
- вход-выбор вызова — список строк таблицы `from` и «формулой…» (`call-editor.tsx: ChoiceArg`). Строка
  хранится как раньше литералом (`"мудрость"`); ссылка (`@save_by`) открывает формулу. Сводка вызова и
  пересказ показывают подпись строки («Мудрость») — `choice-rows.ts: pickedRow`.

## Что не меняется

Формат данных и образцы, раскладка, существующие фишки и их подписи, стол.

## Чего здесь нет

Видимость имён по месту по-прежнему считают два места движка: `references.ts: chainRefs` (проверка) и
`names-at.ts` (редактор). Свести их — отдельная работа: проверка ведёт по ним ещё и порядок шагов, руки
«Если» и затравки подписок, переписать это вместе со справочной — риск без пользы для этой задачи.
Справочная путей от этого не зависит.

Расчёт сам ходит по путям ещё в нескольких местах (`navigate.ts: walk/reach`, `engine/refs.ts`,
`core/run.ts: cellOf`, `sheet-columns.ts: rowPath/rowSteps`). Здесь к справочной подключён только
`resolveAddress` — то место, где расчёт молчал. Остальные проверяют колонку сами и уже говорят словами;
перевести их на `walk*` — отдельный шаг без видимой разницы.

## Проверка

- Движок: опечатки из таблицы выше — каждая даёт ошибку словами; верные пути — без ошибок;
  `walkSheet`/`walkColumns` на путях D&D и SR (глубина за три шага).
- Веб (`effects/name-paths.test.tsx`): карточка «Ресурсы классов после отдыха» показывает «ресурс → Осталось»,
  не `left`; вход «Чем спасается» у «Изгнания нежити» — список с «Мудростью»; «Только если» у «Щита»
  предлагает «Бросок атаки — попадание». Тестовый помощник `within().formula` сам выбирает «формулой…».
- Полный прогон пакетов в конце.
