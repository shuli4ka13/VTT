## Вердикт

**В движке ошибки нет.** Штраф поддержания работает: одно заклинание — −2 кубика, два — −4, три — −6.
**Проблема была в экране:** два разных механизма выглядели одинаково, и не было видно, какой складывается.

> **Где правка записана, так она и складывается.**
> **Число в самом эффекте складывается всегда.**
> **Слово из «Правил» подчиняется правилу этого слова — по умолчанию оно действует на бросок один раз.**

---

## Часть 1. Что происходит, когда кто-то бросает

Пример — стол «владик шадуоран». Мета держит два заклинания («благословить» и «Проклятие») и бросает
«Самообладание». Её обычный набор — 6 кубиков.

1. **Собрать правки со всех листов за столом** — не только с Меты: правка на чужом листе тоже может касаться её
   броска (в D&D «Лежит» на цели даёт помеху тому, кто по ней бьёт).
2. **Отобрать те, что касаются этого броска.** «Кого касается» («бросает носитель», «бросают против носителя»,
   «всех — без условия») и «Какие броски». У Меты подходят две правки «кубики −2» с двух её «Поддержаний».
3. **Разложить на две кучки:** числа («кубики −2», «прибавка +1») и слова («Преимущество», «Помеха»).
4. **Свести каждую по её правилу.** Числа — сложить: −2 + −2 = −4. Слова — по правилам слов (части 3–4).
5. **Бросить и записать:** 6 − 4 = 2 кубика.

Журнал: `Мета бросает «Проверка: Самообладание»: [5, 5] (Поддержание, Поддержание) — успехов: 2`.

Шаг 2 решает, **какие** правки участвуют. Шаг 4 — **как** они складываются. «Какие броски» меняет только шаг 2.

---

## Часть 2. Число в эффекте

**Что это.** Правка с величиной: «−2 кубика», «+1 к броску», «+1к4 к броску».

**Где.** «Что делает, пока висит» → «+ правка вызова» → «Чей вызов: Бросок» → «Что правим: **кубики**» (или
«**прибавка**», «**порог**») → «На сколько: −2».

**Как складывается — всегда.** Каждый висящий эффект и каждая его копия отдаёт своё число, движок суммирует.
Сравнение: две одинаковые монеты по рублю — это два рубля, а не один.

**Примеры:**
- Мета: 0 «Поддержаний» — 6 кубиков, 1 — 4, 2 — 2.
- D&D, Арвен, проверка Силы, выпало 15, модификатор +4. Для примера — «Кольцо» (+1) и «Песнь» (+2):
  - ничего: `[15] + 4 = 19`;
  - «Кольцо» и «Песнь»: `[15] + Кольцо: 1 + Песнь: 2 + 4 = 22`;
  - две копии одного «Кольца»: `[15] + Кольцо: 1 + Кольцо: 1 + 4 = 21`.

**Условие: копии должны появиться на листе.** Вторая копия ложится, если у эффекта «Если наложить второй раз:
**копится**» (не «обновляется» и не «второй раз ничего не делает»), или если эффект — якорь, а у кнопки
«Сколько якорей: свой на каждое действие» (так у ваших «благословить» и «Проклятие»; у вашего «Поддержания»
повтор не настроен — копии кладёт привязка). У состояний образца D&D стоит «обновляется»: два
«Благословления» — одна копия, один +1к4.

«Порог» складывается суммой — проверено по коду (`run.ts`, правки порога сводятся `reduce` суммой), прогоном не
проверял. «Метка броску» добавляет метку один раз, как во множество.

**Технически.** Числа — **список**: элемент от каждой подходящей правки каждой копии; свёртка — сумма.

## Часть 3. Слово из «Правил»

**Что это.** Не число, а название приёма со своим описанием. D&D: «Преимущество» — докинь кость и оставь лучшую;
«Помеха» — докинь и оставь худшую.

**Где.** Слово описано один раз в «Правила» → «Правки броска». Эффект только называет его: «+ правка вызова» →
«Бросок» → «Что правим: слово из «Правил»» → «Какое слово: Помеха».

**Как складывается — по умолчанию никак.** Слово у броска либо есть, либо нет. Сравнение: вторая табличка
«Вход свободный» не делает вход «вдвойне свободным».

**Примеры (Арвен, кости 15 и 4):**
- «Отравлен» (Помеха): `[15, 4] → 4 (Помеха) + 4 = 8`;
- «Отравлен» и «Испуган» (обе Помеха): `[15, 4] → 4 (Помеха) + 4 = 8` — помеха одна.

Так устроен образец D&D и записано в `docs/roll-edits-v2.md`: «Ослеплён и Отравлен — одна помеха». По книге
игрока D&D, насколько я помню, так же (выписки по D&D в `docs/` нет).

**Технически.** Слова — **множество** имён; добавить уже лежащее имя — множество не меняется.

## Часть 4. Гашение

**Где.** «Правила» → «Правки броска» → у слова строка «Гасит» → «+ слово…».

**Как работает.** Если у броска есть оба слова пары — не действует ни одно.

- «Ему помогают» (Преимущество) + «Отравлен» (Помеха): `[15] + 4 = 19 · погасили друг друга: Преимущество, Помеха`.
- «Ему помогают» + «Отравлен» + «Испуган»: тоже обычный бросок — по умолчанию помеха одна, сколько бы её ни дали.

Пометку «погасили друг друга» журнал пишет с этой ветки; раньше строка была просто `[15] + 4 = 19`.

---

## Главный пример: оба вида в одном броске

Две копии «Кольца» (+1, «копится»), «Ему помогают» (Преимущество), «Отравлен» и «Испуган» (Помеха):
`Арвен бросает «Проверка: Сила»: [15] + Кольцо: 1 + Кольцо: 1 + 4 = 21` — числа сложились (+2), слова погасились.

Без «Ему помогают»: `[15, 4] → 4 (Помеха) + Кольцо: 1 + Кольцо: 1 + 4 = 10` — числа сложились, слово одно.

## Часть 5. Поддержание целиком — ваша система «владик шадуоран»

1. У «благословить» и «Проклятие» привязка к якорю «Поддержание», «Сколько якорей: свой на каждое действие» —
   каждое нажатие кладёт новую копию.
2. На «Поддержании» одна правка: «Бросок → кубики → −2, бросает носитель» — **число**.
3. Мета нажала оба. На ней две копии.
4. Бросок «Самообладания»: обе правки подходят, −2 + −2 = −4.
5. Журнал: 6 кубиков → `[5, 5, 5, 5] (Поддержание)` → `[5, 5] (Поддержание, Поддержание)`.

Кубики словом не отнять (слово умеет только докидывать), а «за каждое» словом не посчитать — часть 6.

---

## Часть 6. Исключение: «по разу от каждого разного эффекта»

У слова в «Правила» → «Правки броска», в строке «Гасит», выбор «одно на бросок»
(по умолчанию: сколько бы эффектов ни дали слово) или «по разу от каждого разного эффекта». Во втором случае слово считается по **разным эффектам**
(«такой-то эффект на таком-то листе»), а **копии одного эффекта — один источник**.

- «Ему помогают» + «Отравлен» + «Испуган»: `[15, 4] → 4 (Помеха) + 4 = 8` — помех две, преимущество одно,
  гасятся один к одному, остаётся помеха.
- Две копии одного «Отравлен»: `[15, 4] → 4 (Помеха) + 4 = 8` — одна помеха.
- Shadowrun: слово «Тест +1» на «Поддержании». Одно «Поддержание» — 13 успехов (12 + 1); два — **13**; «Поддержание»
  и другой эффект с тем же словом — 14.

Поэтому «за каждое заклинание» — только числом.

## Часть 7. Технически: что хранится и как сводится

Число — в определении эффекта (`effects.поддержание.modifiers`):
```json
{ "kind": "edit", "call": "roll", "param": "count", "op": "add",
  "value": { "expr": "-2" }, "if": { "expr": "@бросающий == @носитель" } }
```
Копии — на листе Меты (`effects`):
```json
[ { "effectId": "поддержание", "inst": "i1",   "args": { "действующий": "meta" } },
  { "effectId": "поддержание", "inst": "i1~2", "args": { "действующий": "meta" } } ]
```
Наложенное на цели помнит свою копию:
```json
{ "effectId": "благословение", "bond": { "sheet": "meta", "effect": "поддержание", "inst": "i1" } }
```
Слово — в словаре (`roll_edits`, D&D):
```json
"advantage": { "label": "Преимущество", "ops": [ { "op": "addDie" }, { "op": "keepBest", "n": 1 } ], "cancels": [ "disadvantage" ] }
```
«По разу от каждого разного эффекта» — поле `"stacks": true`. Эффект называет слово:
```json
{ "kind": "edit", "call": "roll", "param": "edits", "edit": "disadvantage", "tags": ["проверка"], "if": { "expr": "@бросающий == @носитель" } }
```
«Какие броски» — это те же `tags` (бросок несёт всё), `anyTags` («Или хотя бы одно из»), `notTags` («Кроме»).
Правило броска даёт своим броскам метку-ключ (`проверка`); её же вручную несут многие броски-шаги со своей
костью (в Shadowrun 12 таких, «Колдовство» среди них) — поэтому «Проверка» в «Какие броски» значит «броски по
полям правила и броски-шаги с меткой «проверка»».

Шаг 4 (`core/edits.ts: rollEdits`):
```
отобранные = правки со всех листов, у которых совпали вызов, «Кого касается» и «Какие броски»
кубики     = сумма(п.число для «кубики»)                     # список → сумма
прибавки   = [п для «прибавка»]                               # каждая отдельно, итог — сумма
источники  = {слово: множество (лист, эффект)}                # копии схлопываются
сколько[с] = |источники[с]|, если stacks, иначе 1
пара a, b с «Гасит»: оба stacks → вычесть меньшее; иначе — обе в ноль
каждое слово применить сколько[с] раз; погасшие — в журнал «погасили друг друга»
```
