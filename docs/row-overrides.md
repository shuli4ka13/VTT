# Строка уточняет колонку: умолчание и пределы

## Зачем

У строк одной таблицы бывают разные умолчания и пределы при одной колонке «Значение». Shadowrun: «Тело» — по
умолчанию 3, не выше «предел метатипа + бонус»; «Преимущество» — по умолчанию 2; «Магия» — пусто, не ниже 0, не выше
«6 + посвящение». Сейчас колонка задаёт пределы одни на все строки, поэтому образец завёл одиннадцать отдельных полей
листа вместо таблицы и справочник-обход «у цели», чтобы связать их обратно (`samples/shadowrun.world.json`, `attributes`).

## Что уже есть

У строки таблицы `row.view[колонка]` — свой «вид» клетки (`schema/world.ts: cellView`): `label`, `roll`, `default`.
`sheet-columns.ts: viewOf` складывает вид колонки и вид строки (строка поверх), `rowFields` строит поле клетки с этим
видом. Умолчание строки уже пишет образец листа (`sheet-sample.tsx: setSample`). Пределы берутся только с колонки
(`boundsOf(column)`).

## Решение

Правило одно: **колонка задаёт общее, строка может перебить** — так же, как клетка строки перебивает «Формулу для всех
строк».

- `cellView` получает `min` и `max` — того же вида, что у колонки: число или формула `{ expr }`.
- `viewOf` отдаёт их вместе с остальным; `rowFields` берёт пределы из вида строки, а при их отсутствии — с колонки.
  Подстановка `@строка` и шаблонов `{колонка}` в пределах работает, как сейчас для пределов колонки.
- Ничего нового в движке исполнения: «Изменение», операции листа и чтение уже берут пределы из поля клетки
  (`field.value.min/max`), а поле строится в одном месте.
- Линт формулы пределов не проверяет ни у колонки, ни у строки — это отдельная дыра, здесь не закрывается.
- Переименование строки, таблицы и поля обходит данные таблицы целиком (`integrity.ts: repathRow`, `keys.ts`) — формулы в `row.view` переименовываются вместе с остальными.
- Проверка вида поля (`views.ts: viewNeeds`: точкам и полосе нужен «верх») смотрит на колонку: у таблицы, где верх только у строк, общий верх на колонке всё равно нужен.
- Пустое в виде строки — ключа нет: берётся с колонки. Умолчания в данные не пишутся: значение, равное общему, снимает ключ (`apps/web/.../row-view.ts: setRowView` — одна функция для образца листа и служебных колонок).

## Конструктор

Карточка колонки — общее («По умолчанию», «Не ниже», «Не выше»), как сейчас. В таблице строк под «ещё» — служебные
колонки «По умолчанию», «Не ниже», «Не выше» этой колонки: пустая клетка — «как у колонки» (серым показывается общее),
заполненная — своё для строки. Формула — тем же полем формулы, что у колонки. Служебные колонки — не колонки таблицы:
это редактор `row.view`, в данных колонок не появляется.

## Чего здесь нет

Этапы сложения правок (`column.stages`) по строкам — отдельный вопрос, владелец не решил. Пересборка характеристик
Shadowrun таблицей ждёт этапов: у физических и ментальных характеристик они разные.
