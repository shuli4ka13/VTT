# Виды полей листа

Заказчик 03.10.2026: палитра из хаба (`docs/research-hub/kontroly.html`, 12 контролов) — «UI не только что на листе, но и как отображается». Подпись в конструкторе — «Вид». Старые контролы и выпадающий список снести, собрать новое красивое.

## Решения

1. **Вид — одно понятие.** Колонка `control`, исключение строки — `row.view[колонка].control`. Ключ схемы прежний (`control`), подпись в интерфейсе «Вид». Один редактор вида — галерея плиток с живым превью (настоящий контрол на образцовом значении), а не выпадающий список. Та же галерея и для колонки, и для строки.

2. **Двенадцать видов + «обычное поле»** (по типу значения):
   - число: `signed` «+3» (со знаком), `big` «крупно» (КД, инициатива), `stepper` −/+, `slider`, `pips` точки, `charges` круговой запас («пицца»), `bar` полоса;
   - да/нет: `toggle`;
   - выбор одного: `ring` кружок по ступеням, `choice` кнопки-сегменты;
   - выбор нескольких: `chips` метки;
   - кость: `die`.

   Палитра хаба → наши: радио-множитель и сегменты режима = `choice`; преимущество/помеха — правка броска при заявке, на листе это `choice` из трёх, если автору надо; кубик-кнопка — не вид, а кнопка «бросить» у поля с броском.

3. **Вид у посчитанного поля.** Посчитанное поле получает вид без управления (только показ): `signed`, `big`, `pips`, `charges`, `bar`, `toggle` (лампа да/нет), `chips` (список). Управляющие (`stepper`, `slider`, `ring`, `choice`, `die`) посчитанному не предлагаются. Если значение не того типа (например, текст в `bar`) — показ обычным полем, без ошибки.

4. **Пределы.** `pips`, `charges`, `bar`, `slider` берут максимум из `max` колонки (число или формула), минимум — `min` или 0. Без максимума: `bar` — по текущему, `pips`/`charges` — до 5, `slider` — превращается в `stepper`. Точек и секторов не больше 20.

5. **Список значений.** Колонка `kind: choice` + `many: true` теперь допустима и в листовой таблице (single) и во вводимой клетке строки. Значение — массив значений вариантов: `storedValue` += массив чисел/строк. Умолчание — `[]`. Формулы уже читают списки (`есть(@сопр, "огонь")`, `сколько(@сопр)`). Шаг «Изменить» с прибавлением или вычитанием по списку падает в движке (apply.ts: «держит не число»); «установить» список пишет. Ревью Sonnet: провод `sheet:set` теперь берёт `storedValue`, умолчание колонки и `view.default` принимают список, `FieldValue.stored.many`, запись сравнивает значения глубоко (без ложных «изменений» в журнале), `set` отвергает список в одиночное поле и наоборот. Пустая клетка списочной колонки — `[]`, не `""` (золотой снимок D&D обновлён только этим).

6. **Полоса** красит заливку по доле: больше половины — ok, половина и меньше — warn, четверть и меньше — danger. Без настроек.

7. **Вид строки** — в карточке поля-клетки на вкладке «Лист»: «как у колонки» или своя плитка; совпадение с колонкой снимает ключ, пустой `view` удаляется.

8. **Снос.** `sheet/controls/index.tsx`, ветки контролов в `field-cell.tsx`, `Select` «Вид» и старые стили `.pip`/`.bar` — сносятся. Новое: `sheet/views/*` (по файлу на семью видов), `sheet/views.css`, галерея `screens/constructor/view-gallery.tsx`.

9. **Не делаем:** настройку цветов и порогов полосы, анимацию бросков, «потраченную» способность (отдельный шаг вместе с экраном игры).

## Приёмка

- тесты контролов переписаны: каждый вид рисуется и для ввода, и для показа; клик пишет нужное значение;
- галерея: плитки отфильтрованы по типу; выбор пишет `control`, «обычное поле» снимает ключ;
- round-trip и опись путей на шести пресетах зелёные (галерея понятна пробе);
- в браузере: копия D&D — модификатор «+3», КД крупно, ячейки точками, ХП полосой с цветом; список сопротивлений метками.
