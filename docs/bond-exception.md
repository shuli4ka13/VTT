# Привязка к якорю: исключение у шага «Наложить»

## Что есть

Эффект-кнопка с `bond { effect, by, many?, if?, args? }` кладёт на того, кто действует, якорь
(висящий эффект `bond.effect`) и привязывает к нему всё, что сам накладывает шагом «Наложить»:
на наложенном пишется `bond { sheet, effect, inst? }`. Сняли якорь — привязанное спадает
(`events/bonds.ts: sweepBonds`). «Одно» (D&D, концентрация) — новый каст снимает прежний якорь;
«каждое отдельно» (Shadowrun, поддержание) — свой экземпляр якоря на каждый каст. Единица привязки по
обеим книгам — одно заклинание (один каст), а не отдельное наложение. Вложенный «Вызвать» привязку не
наследует.

## Чего не хватает

Заклинание, у которого часть наложений длится сама по себе (ослепление держится концентрацией, ожог
остаётся), сейчас собирается только выносом второго наложения в отдельный эффект и шагом «Вызвать» —
обход, по экрану не читаемый.

## Сверка с принятыми решениями

- `docs/library-functions.md` §5в и `docs/sr6-sustain.md`: «держание — не шаг», шаг «держать» отвергнут;
  в `sr6-sustain.md` записано «если появится поддерживаемое заклинание, которое накладывает ещё и не держимое, —
  вернуться к вопросу отдельно». Это тот случай (владелец, 13.11.2026). Решение не делает держание шагом:
  привязка остаётся свойством кнопки, у шага — только исключение.
- `docs/model-v3.md`: держится только наложенное самой кнопкой, во вложенные вызовы не передаётся — не меняется.

## Решение

- Привязка остаётся свойством эффекта: по умолчанию привязано всё, что эффект накладывает (как по книге).
- У шага `status` в режиме «наложить» — флаг `unbound: true`: это наложение не привязывается к якорю
  (на наложенном нет `bond`, экземпляр якоря из-за него не заводится). Умолчание `false` не пишется.
- «Проблемы»: `unbound` в эффекте без `bond` — ошибка (отвязывать не от чего); `unbound` в режиме
  «снять» — ошибка (слот не виден).
- Экран: выбор «Когда сняли якорь» в карточке «Состояние» виден только у эффекта с привязкой и только при
  «вешаем»; «снимаем», снятие привязки и смена вида шага убирают отметку. Кнопка привязки в свойствах — только
  у эффекта, где есть шаг «Наложить» или привязка уже стоит. Свёрнутый шаг говорит «Остаётся, когда сняли якорь».
- «Одно»: якорь кладётся на колдующего после доставки по каждой цели, как и прежде, — даже если там легли только
  наложения «остаётся». Эффект, у которого все наложения «остаётся», ловят «Проблемы» («привязывать нечего»).
- Повторное наложение с обновлением (`reapply: refresh`) заменяет запись целиком: решает последнее — привязанное
  становится непривязанным и наоборот.
- Слова экрана: кнопка «+ привязка к якорю», поля «Якорь», «У кого якорь», «Сколько якорей» («один — новое действие
  отпускает прежнее» / «свой на каждое действие»), у шага — «Когда сняли якорь: спадает вместе с ним / остаётся».
  Строки журнала («… спало …: держать стало нечем») не меняются.
- Формат меняется добавлением необязательного поля; образцы не затронуты (ни одно наложение образцов не
  должно оставаться после потери якоря).

## Проверка

- Движок: каст с двумя наложениями, одно `unbound`; сняли якорь — спадает только привязанное; в режиме
  «каждое отдельно» наложение `unbound` без привязанных соседей экземпляр якоря не заводит.
- Линт: две находки выше.
- Урок «Заклинания»: якорь ложится сам; привязанное спадает вместе с ним.
