# Атака, цена-аргумент, кнопка записи

Заказчик 06.10.2026: «язык программирования в понятном UI»; «бонус атаки выводится сам — не наравне с тем, что заполняют»; «никакого английского»; «снять ресурс, неважно какой — это часть логики». Решение принято после трёх раундов Sonnet + Fable (brief в scratchpad сессии), вариант цены — заказчика.

## Решения

1. **Одна «Атака» на систему, различия — аргументами.** D&D: `strike` поглощает «Заговор: бросок атаки» и «Заклинание: бросок атаки». Входы: кто действует, цели, бонус атаки, кость урона, сколько костей (1), прибавка к урону (0), тип урона, источник урона, состояние при попадании (необяз.), **цена**. Механики разных систем не сливаются (крит D&D, 13th Age, Daggerheart разный).

2. **Бросок и урон — у каждой цели свои** (D&D: правило «каждая атака — свой бросок атаки и урона»; площадные со спасброском — урон один на всех, не трогать). Шаги атаки и урона — после «Для каждого из», `against: @цель`.

3. **Цена — аргумент.** Вход «Цена» вида «эффект» (из блока «Стоимость»); в `cost` эффекта — вызов `@цена`. «Атака» не знает, чем платят.
   - Платы — маленькие эффекты блока «Стоимость»: «Потратить (что: поле, сколько)» — снять ресурс; «Одна атака из действия» (логика «Дополнительной атаки»); «Действие и ячейка» (составная, спрашивает круг).
   - У входа — умолчание (`default`), иначе выданные кнопки без аргументов становятся бесплатными.
   - Вызов платы из входа: `emit.effect` — формула (как у `status`); пусто — шаг пропущен.
   - Вопрос платы («каким кругом») доходит до игрока: `asksOf` собирает вопросы плат, выбранных константой кнопки или умолчанием; ответы (`inputs`) видны во вложенном вызове.
   - Вход вызываемого эффекта с именем свойства записи берёт его сам (то же правило, что у кнопки) — плата «ячейка» читает круг заклинания у записи.
   - Cyberpunk/Shadowrun: цена, зависящая от вопросов механики, остаётся внутри эффекта.

4. **Редактор кнопки** (тип записи → «Что запись даёт владельцу»): группы — «Заполняют у каждой записи» (вход = свойство записи), «Спросят за столом», серым ниже «Считается само» (формула, без поля ввода; «изменить» по щелчку), «ещё» — кто действует / цели. Без внутренних имён.

5. **Компендиум:** сначала то, что заполнить; ниже серым «Считается само» — откуда берётся (фишки путей), цена.

6. **Без английского:** `таблица("id", @ссылка, "колонка")` → путь `@ссылка.колонка` (фишка [Способ атаки · Бонус атаки]); где нужен поиск (урон ярости, ячейки) — показывать названия таблиц.

## Не сделано / потом
- Спасбросковые заклинания D&D остаются на эффекте-основе `spell` (две схемы траты ячейки) — перевести следом.
- Сверить по правилам Daggerheart, Cyberpunk, Shadowrun: бросок один на всех целей или у каждой свой.
- Точка после фишки в редакторе формул продолжает путь.
- «Атака по возможности» — кнопка с ценой «реакция» (движения в движке нет).
