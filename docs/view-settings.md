# Настройки видов и снос зашитого

Заказчик 05.10.2026: «для каждого контрола нужны свои вещи — границы для ползунка, точек, круга зарядов»; «как понять, что первая ступень — нет, а вторая — владение?». Аудит Sonnet нашёл в видах зашитые слова и молчаливые подмены. Продолжение `docs/sheet-views.md`.

## Решения

1. **Вид — объект.** `control: { kind, step?, worse?, yes?, no? }` у колонки и у `row.view[колонка]`. Строки (`"pips"`) больше нет — образцы переписываются скриптом. Умолчания не пишутся: `step` 1, `worse: "low"` (плохо, когда мало), `yes`/`no` — «да»/«нет».
   - `step` — у «Минус и плюс» и «Ползунок»;
   - `worse` — у «Полосы»: `low` — красная, когда мало (хиты), `high` — когда много (перегрузка, опыт до порога);
   - `yes`/`no` — подписи «Переключателя».

2. **Границы — свойства значения, не вида.** Верх и низ остаются `max`/`min` колонки: одна граница и для показа, и для проверки записи. Это число или формула: `3` или `@hp_max` / `@строка.max`. Отдельных колонок под границы не заводится; кнопка «+ колонка для верха» заводит колонку «Максимум …» в той же таблице и ставит верх ссылкой на неё.

3. **Что каждому виду обязательно:**
   | вид | обязательно |
   |---|---|
   | Точки, Круг зарядов, Полоса | верх |
   | Ползунок | низ и верх |
   | Кружок ступеней, Кнопки выбора | варианты: тип «выбор» + таблица |
   | Метки | тип «выбор», «несколько», таблица |
   | остальные | ничего |

   Не хватает — на листе вместо вида «—» с подсказкой (чего не хватает), в конструкторе плитка помечена «задайте верх»/«нужна таблица вариантов», в «Проблемах» — предупреждение линта. Никаких молчаливых подмен (ползунок → минус и плюс, 5 точек, полная полоса, первая ступень).

4. **Кружок ступеней — только из вариантов.** Зашитые «нет/владение/мастерство» и цифровые ступени сносятся; кружок — вид типа «выбор». Значение вне вариантов (пусто) — «—», клик — первая ступень.

5. **Переключатель — только у типа «да/нет».** Число как «да» больше не читается (код не решает, что у числа «да»).

6. **Типы → виды** (`FITTING`): число — со знаком, крупно, минус и плюс, ползунок, точки, круг зарядов, полоса; да/нет — переключатель; выбор — кружок, кнопки; выбор нескольких — метки; кость и текст — кость.

7. **Пусто ≠ 0.** Числовые виды при пустом значении показывают «—» (точки не закрашены, полоса «— / 45»), а не ноль.

8. **Больше 20 точек/секторов** — на листе «n / верх» текстом, в конструкторе пометка «много для точек — возьмите полосу».

9. **Мелочи:** «нет» при нуле точек → «—»; у кости нет подсказки «1к6»; подсказки плиток галереи без слов D&D.

10. **Панель настроек вида** — под галереей «Вид», только поля выбранного вида: верх/низ (те же поля колонки, из «ещё» они уходят, когда вид их требует), шаг, «плохо, когда мало/много», подписи да/нет, «ступени — строки таблицы «X»». Вид одной строки берёт настройки колонки; своя панель у строки — только выбор вида.

11. **Образцы (скриптом):**
    - «Идёт бой» (`стол.battle`, D&D, Киберпанк, 13th Age, Shadowrun) — тип «да/нет»; эффекты ставят `да`/`нет`; `@стол.battle >= 1` → `@стол.battle`; тесты движка, где `battle: 0/1`, — на `false/true`;
    - D&D: таблица «Владение» (`proficiency`, ключ число: 0 нет, 1 владение, 2 мастерство); `skills.prof` — выбор из неё, кружок; `abilities.save_extra` — да/нет, переключатель, формула `save_prof`: `большее из(если(@строка.save_extra, 1, 0), …)`; значения листов образца 0/1 → `нет`/`да`;
    - все `control: "x"` → `{ "kind": "x" }`.
    Золотой снимок меняется только типами этих значений; исходы и журнал — прежние (проверить дампом, как в f2105a01).

## Приёмка
- тесты видов: обязательное отсутствует → «—» и подсказка, без подмен; кружок без вариантов — «вариантов ещё нет»; пусто ≠ 0; шаг; `worse`; подписи переключателя;
- линт: вид без обязательного — предупреждение;
- round-trip, опись путей (новые пути `control.step/worse/yes/no` — «есть»), C2, C4 зелёные; снимок — только ожидаемые расхождения.

## Сделано (05.10.2026)

Всё по решениям 1–11 с поправками ревью Sonnet: сид-значения `battle` и тесты сервера переведены; запись проверяет тип (`model/sheet-columns.ts: misfit`, в `apply set` и `perform set`); у `prof` `default: 0`, у `save_extra` `default: false`; таблица ступеней названа `prof_steps` (тест стережёт старую `proficiency`); правила видов — один модуль движка `model/views.ts` (линт и галерея читают его); вид строки хранит только `kind`, настройки склеиваются с колонкой (`viewOf`). Журнал пишет «нет → да». Снимок: исходы прежние, расходятся только строки «Идёт бой» и производные хеши (проверено дампами).

**Не сделано, вопрос заказчику:** у Daggerheart нет верной формулы верха для хитов и стресса (у противников они в `adversary_hp`/`adversary_stress`, а «клеток» считается только у героев) — точки там честно показывают «—» и линт предупреждает.
