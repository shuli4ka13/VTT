# Собрать бросок и удар с нуля — по системам

Стенд: http://localhost:8302, вход под именем «Стенд». Миры для сборки называются «… · с нуля»: таблицы листа и листы
на месте, эффектов, бросков, правок броска и записей в книге нет. У Shadowrun такого мира нет.

Руками пройден только D&D (13.11). Остальные системы выписаны из лёгких образцов теми же словами экрана — где экран
разойдётся с написанным, это ошибка шпаргалки, а не ваша.

## Общий порядок (одинаков везде)

1. **Бросок с листа.** Главная → «Автор системы» → «Продолжить работу» → система «… · с нуля» → вкладка «Правила».
   Слева в «Разделах правил» — «Броски» (панель свёрнута — развернуть стрелкой «»»). В карточке «Броски» нажать
   «+ бросок», вписать название, в строке «Бросают» списком «+ поле…» добавить поля, выбрать «Кость» и
   «Число поля — это».
2. **Эффект.** Вкладка «Эффекты» → «+ кнопкой». Вписать название вместо «Новый эффект». В «Что приходит» —
   «+ ещё одно»: название «Цели», «Вид» — «список листов», в поле «Каждый» вписать «Цель». Дальше шаги.
3. **Кнопка у вещи.** Вкладка «Вещи и умения» → слева развернуть «Книги» и найти тип оружия → в разделе
   «Кнопки на листе» нажать «+ кнопка» → в «Вызывает эффект» выбрать свой эффект → наверху «Опубликовать».
4. **Запись в книге.** Главная → «Автор книги» → выбрать свою систему → у «… · с нуля · основная книга» нажать
   «открыть» → в «Завести запись» нажать тип оружия → вписать название → «Опубликовать компендиум».
5. **Стол.** «Игра» → в «Собранных мирах» у своего мира «Создать стол» → «Персонаж» → выбрать лист. У полей из
   шага 1 появится «бросить». Вкладка листа «Снаряжение» → «Добавить вещь» → развернуть папку → щёлкнуть запись.
   Потом «Стол» → щёлкнуть действующего, щёлкнуть цель → нажать кнопку записи.

## Что нужно знать про поле формулы

- Щелчок по числу или пустому полю открывает строку формулы наверху экрана. Закончить — Enter или «готово».
- Имя поля, входа или шага набирается просто словами, без значков: начать набирать «цель» — в списке под строкой
  появятся подходящие, Enter берёт первую (или щёлкнуть нужную). Имя встаёт фишкой. После фишки ставится точка и
  набирается начало названия поля: «.класс б» → в списке остаётся «Класс брони» → Enter. Точку ставить после
  выбранной фишки, а не после набранных букв: «цель.класс» одним куском подсказку не откроет.
- Прежнее число само не исчезает: сначала стереть «10», потом набирать. Иначе красная строка «лишний текст после
  конца выражения».
- По Enter берётся первая строка списка. Слово, которое точно совпало с названием, идёт первым: «цель» даст «Цель»,
  а не «Цели». Слова самой формулы («если», «округлить вниз», «и», «или», «не»…) стоят в том же списке в группе
  «формула» и идут выше имён — если нужное имя не первое, щёлкнуть по нему. Внутри кавычек подсказки нет.
- У броска после выбора имени итоги не открываются сами: поставить точку после фишки (или щёлкнуть по фишке) —
  откроется список: бросок целиком и его итоги. В числе нужен «сколько вышло всего» — выбрать щелчком или Enter.
  Одно имя без итога работает, но «Проблемы» скажут «не выбран итог».

## Какие поля ставить в «Бросают»

В бросок идут поля, у которых на листе должно появиться «бросить», — итоговые числа (модификатор, «всего», «итог»),
а не сырые значения. Одно поле — в одном броске. Так стоит в мирах «… · лёгкий» — там можно подсмотреть.

## D&D 5e — пройдено руками

**Бросок.** Название «Проверка»; поля «Характеристики → Модификатор» и «Навыки → Навык»; «Кость» — «Ведущая кость»;
«Число поля — это» — «прибавка к выпавшему» (оба последних стоят сразу).

**Преимущество и помеха** (не обязательно). В карточке «Правки броска» → «+ правка», название «Преимущество»,
в «+ добавить…» выбрать «добавить кость в набор», затем «оставить лучшую». Вторая правка «Помеха»: «добавить кость
в набор», «оставить худшую». У «Преимущества» в строке «Гасит» списком «+ слово…» выбрать «Помеха».

**Эффект.** Название любое, например «Удар оружием».

1. «+ бросок». В списке справа от «бросает» вместо «Ведущая кость» — «Сила → Модификатор». Под строкой появится
   «по правилу „Проверка“ из „Правил → Броски“».
2. «+ для каждого из списка» — в нём «Цели».
3. «+ проверка». Встанет «бросок не меньше ≥ 10». Щёлкнуть по 10, стереть, набрать «цель» → Enter → «.класс б» →
   Enter → Enter. Должно получиться «бросок не меньше ≥ Цель · Класс брони».
4. В карточке проверки нажать «+ по итогу». Появится ветка «успех:».
5. В ветке «успех:» в списке «+ шаг» выбрать «бросок». Вместо «Ведущая кость» — «своя кость…», в поле рядом
   вписать «1к8», Enter. Имя шага слева заменить на «урон».
6. Снова «+ шаг» в ветке «успех:» → «изменение». «У кого» — «Цель»; «Какое поле» — «Хиты»; «Как» — «отнять»;
   в «Сколько» набрать «урон», Enter, поставить точку и выбрать «сколько вышло всего».

Над шагами справа должно стоять «эффект верный · шагов 5».

**Вещь.** Тип «Оружие» лежит в «Книги» → «Книга» → «Снаряжение».

**Что получилось у меня за столом.** Арвен, модификатор Силы: «[1] + 4 = 5». Удар по Огру: 10 против Класса
брони 11 — провал; 12 — попадание, Хиты 59 → 56.

## Остальные системы — отличаются только бросок и шаги

### Киберпанк RED

- **Бросок:** «Ведущая кость» (к10); «прибавка к выпавшему»; поле «Навыки → Всего».
- **Шаги:** бросок — «Пистолеты → Всего»; для каждого из «Цели»; проверка — «не меньше ≥ 15» (стереть 10, вписать 15);
  «+ по итогу»; в «успех:» — бросок «своя кость…» «3к6», имя «урон»; изменение: «Цель», «Хиты», «отнять», «урон» → точка →
  «сколько вышло всего».
- **Упрощено:** сложность 15 вместо таблицы по дистанции; броня не вычитается.

### 13th Age

- **Бросок с листа:** в образце его нет, шаг 1 можно пропустить.
- **Шаги:** бросок — оставить кость «к20», «Кто действует»; для каждого из «Цели»; проверка — «не меньше ≥»
  «цель» → Enter → «.защита» → «Защита от оружия (КЗ)»; «+ по итогу»; в «успех:» — бросок «1к8», имя «урон»; изменение:
  «Цель», «Хиты», «отнять», «урон» → точка → «сколько вышло всего».
- **Упрощено:** бросок без бонуса атаки оружия.

### Blades in the Dark

- **Бросок:** кость «пул действия к6»; «сколько костей бросить»; поля — рейтинги действий: «Драка», «Скрытность»,
  «Убеждение» и остальные.
- **Шаги:** бросок — поле «Драка»; для каждого из «Цели»; проверка — «не меньше ≥ 4».
- **Вещь:** тип «Действие» (кнопка у записи: «Автор книги» → запись → «Свои кнопки» → «+ кнопка»).
- **Упрощено:** нет часов тревоги и правила «рейтинг 0 — две кости, худшая»; исход читается в журнале.

### Daggerheart

- **Бросок:** кость «Кости двойственности»; «прибавка к выпавшему»; поля — шесть черт: «Проворство», «Сила»,
  «Искусность», «Чутьё», «Присутствие», «Знание».
- **Шаги:** бросок — поле «Проворство»; для каждого из «Цели»; проверка — «не меньше ≥» «цель» → Enter → «.сложность»;
  «+ по итогу»; в «успех:» — изменение: «Цель», «Хиты отмечены», «прибавить», в «Сколько» — 1.
- **Упрощено:** всегда один отмеченный хит вместо порогов урона; нет «с надеждой / со страхом».

### Warhammer 40,000 Imperium Maledictum

- **Бросок:** кость «Основная Кость» (к100); «порог: выпало не больше»; поля «Характеристики → Итог» и
  «Навыки → Итог».
- **Сложность** (не обязательно): правки броска со «сдвинуть порог». Знак обратный: чтобы стало легче на 20,
  вписать −20; труднее на 10 — вписать 10.
- **Шаги:** для каждого из «Цели»; бросок — поле «Стрельба → Итог»; «+ если» с условием «бросок → пройден»;
  внутри — изменение: «Цель», «Раны», «прибавить», в «Сколько» — урон числом, например 6.
- **Упрощено:** урон без степеней успеха и брони; степени считаются «порог минус выпало», а не десятками, пока в
  правило не вписаны формулы «Успех, если» и «Степени числом».
- **Не уверен в экране:** шаг «+ если» руками не открывал.

### Fabula Ultima

- **Бросок:** кость «две кости характеристик»; «сколько граней у кости»; поставить флажок «Бросают два поля»;
  поля «Ловкость», «Восприятие», «Сила», «Воля».
- **На листе:** над листом появятся «вторая характеристика» и «сложность» — выбрать вторую, вписать сложность
  (лёгкая 7, средняя 10, трудная 13), нажать «бросить».
- **Шаги:** бросок — поле «Ловкость», рядом «Второе поле» — «Сила»; для каждого из «Цели»; проверка —
  «не меньше ≥» «цель» → Enter → «.защита»; «+ по итогу»; в «успех:» — изменение: «Цель», «Очки здоровья», «отнять»,
  в «Сколько» — 10.
- **Упрощено:** урон 10 вместо «старшая кость + число оружия»; дубль от шестёрок и две единицы исход атаки не
  решают.

## Если что-то пошло не так

- «Проблемы» наверху — список замечаний; «Открыть» ведёт к месту.
- Эффект подписан «не подключён» — у него нет ни кнопки, ни вызова: сделайте шаг 3.
- Система не публикуется — в «Проблемах» есть ошибка (красная), её надо убрать.
- Стенд пересевается с чистой базой при каждом обновлении кода — собранное руками пропадает.
