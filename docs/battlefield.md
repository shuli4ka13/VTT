# Поле боя: положение фишек и дистанция — легко, «на калькуляторе»

Заказ владельца 11.11.2026: стол работает с дистанцией, ходами, режимом боя; посмотреть, как это у Foundry, и сделать
легко. Продолжение `docs/table-v2.md` («Дистанция — отдельная модель с документом»).

## Термины

- **Клетка** — целочисленное место на поле `{x, y}`; поле без картинки, сетка рисуется стилем.
- **Шаг сетки** — сколько метров (или других единиц системы) в одной клетке.
- **Полоса дистанции** — строка справочной таблицы системы с границами «от — до» («вплотную», «близко», …).

## Сделано (12.11)

Схема (`system.grid`, `column.bound`, `param.measure`, `room.places`, сообщения `piece:place` / `room:places`),
движок `engine/place.ts` и линт `measureProblems`, сервер (таблица `room_places`, права в `core/authorize.ts`), поле
на столе и предзаполнение входа, редакторы в конструкторе. Диагональ названа `one | alt | line`. Образец D&D —
сетка 5 фт. Полосы Shadowrun и Daggerheart и шаг Cyberpunk не заполнены — ждут книг (вопросы ниже).

## Как было (11.11)

- Бой: `engine/clock.ts` — `round`, `order`, `active`, `scores`, `sec` (раунд = 3 с); начать, следующий ход, вступить,
  выйти, конец боя, прошло время, сцена, отдых; моменты хода (`events/moments.ts`) и сроки висящего
  (`events/durations.ts`). Полоса боя — `apps/web/src/screens/play/combat.tsx`.
- Дистанция: положений нет. Это вход эффекта, который называет игрок или ведущий (решение 13, `param.ask`), из таблиц
  «Дистанции» (Shadowrun `ranges`, Daggerheart `ranges` — только слова, Cyberpunk `dv_range` — промежутки в метрах).

## Как у Foundry (API v14, прочитано 11.11)

- **Бой** — документ `Combat`: `round`, `turn` (номер в списке), `combatants`, привязка к сцене. Участник `Combatant`:
  `initiative`, `defeated`, `hidden`, фишка и лист, `roundJoined`. Порядок — сортировка по инициативе по убыванию.
  Наш `Clock` покрывает то же (порядок + активный + `scores`); «выбыл» и «скрыт» у нас нет.
- **Сетка сцены**: без сетки, квадрат, шестиугольники; размер клетки в пикселях, `distance` и `units` на клетку;
  расстояние меряет `measurePath` по пути.
- **Фишка** `TokenDocument`: `x`, `y`, высота, размеры, история перемещения.
- О проверке дальности оружия ядром на прочитанных страницах нет ничего; про сроки эффектов (`ActiveEffect`) не читали.
- Тяжёлое у Foundry — холст (PIXI/WebGL): картинки карт, зрение, свет, стены, туман, анимация пути.

Не подтверждено по страницам: правила диагоналей и время на раунд (`CONFIG.time.roundTime`).

## Решение

Берём у Foundry только сетку и `x, y` фишки. Холст, зрение, стены, свет, туман, пути и историю перемещений — нет.

1. **Положение — состояние комнаты, не листа.** `room.places?: { [листId]: { x, y } }` рядом с `clock`. В DTO листа не
   попадает (хранимое ≠ вычисляемое не затронуто). Лист без места — «не на поле», всё работает как сейчас.
2. **Сетка — данные системы** (`system.grid?`): `step` — единиц в клетке, `unit` — подпись («м»), `diagonal` —
   `cheb` (диагональ = 1) | `alt` (5-10-5) | `line` (по прямой, округление вверх). Нет `grid` — нет
   поля, стол как сейчас. Один редактор в «Правилах» → «Бой».
3. **Мера — одна чистая функция** `engine/place.ts: distance(a, b, grid)` — целые числа, без корней кроме `line`.
4. **Движок положений не читает.** Иначе повтор по журналу ломается, когда фишку сдвинули. Мера — подсказка в
   форме действия: вход-дистанция предзаполнен измеренным значением (числом или строкой таблицы), игрок или ведущий
   может поправить, значение уходит в намерение `inputs` как сейчас и пишется в журнал.
5. **Какой вход — дистанция** — помечает автор: у входа эффекта признак «заполнять дистанцией до цели»
   (`param.measure: true`). Только у спрашиваемого входа (`ask`, решение 13) и «для каждой цели» (`perTarget`): у
   каждой цели своя дистанция. Вход-число получает меру в единицах (Cyberpunk «Дистанция, метров» — как есть, сложность
   по `dv_range` эффект ищет сам). Вход-выбор из таблицы — строку, у которой мера между колонками границ: автор
   отмечает в таблице две числовые колонки «от» и «до» (в единицах сетки). Ключ таблицы и её строки не меняются —
   выборы и чтения `@вход.колонка` остаются прежними. Движок не знает имён таблиц и колонок: только отметки.
6. **Сообщение** `piece:place { roomId, sheetId, x, y } | { sheetId, off: true }` (не «токен»: омоним с парсером) —
   одно на бросок фишки, не на движение мыши. Права: игрок — свой закреплённый лист, ведущий — любой. Пока висит
   вопрос — разрешено (листы не правятся). В `room_journal` не пишется: на итог действий не влияет. Хранение —
   колонка комнаты на сервере, миграция по образцу `addHiddenColumn`.
7. **Экран**: поле — CSS-сетка из `div`, фишка — кружок с именем, перенос — перетаскивание или «клик по фишке → клик
   по клетке» (телефон). При выбранной цели — подпись «до Боры: 12 м · близко». Чей ход — кольцо, как сейчас.
   Без картинки карты, без масштаба колёсиком в первой версии; поле прокручивается.

Итог по весу: состояние — словарь из N пар чисел, мера — несколько сложений, отрисовка — N+клетки `div`.
Ни холста, ни библиотек.

## Данные образцов

- Shadowrun `ranges` (ключ `word`) — дописать две числовые колонки «от» и «до» метров; колонка `meters` (текст)
  остаётся подписью. Числа — по книге: в `docs/` метров полос нет — вопрос владельцу.
- Cyberpunk: вход «Дистанция, метров» — число, подходит как есть. Шаг сетки — по книге, проверить.
- Daggerheart `ranges` — только слова; сколько клеток в полосе, в `docs/` нет — вопрос.
- D&D 5e: дистанция — текстовое свойство оружия, входа-дистанции у атаки нет; мера только подписью на поле.

При постройке: обновить `docs/production-differences.md` (строка «Положения фишек, дистанции… нет» и раздел о
минимальном столе) и записать туда сознательные упрощения: без картинки карты, без масштаба, перемещения не в журнале.

## Вопросы владельцу

- Метры полос Shadowrun 6, клетки полос Daggerheart, шаг клетки Cyberpunk — нужны выписки из книг.
- Нужна ли картинка карты под сеткой (загрузка файла) — в первой версии нет.

## Проверка

Движок: `distance` на трёх правилах диагонали; линт `measure` — только у спрашиваемого входа «для каждой цели»,
число или выбор из таблицы с отмеченными границами. Сервер: `piece:place` — права, сохранение (миграция), рассылка,
перезагрузка комнаты. Веб: поле, перенос, предзаполнение входа у каждой цели. Браузер: бой Cyberpunk — выстрел по фишке
в 10 клетках подставляет метры.
